# SPORT KIT — Professional Football Sportswear Showcase Website
> **WEAR THE GAME. LIVE THE PASSION.**

SPORT KIT is a plain professional football sportswear showcase web application built to exhibit premier football club jerseys, training kits, player editions, and authentic accessories from around the world. 

Designed with a luxury sports aesthetic inspired by modern football heritage, the website strictly acts as a showcase platform with direct WhatsApp enquiries and phone/email contacts — completely free of e-commerce checkout and shopping cart mechanics.

## 💻 Tech Stack
- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS v4
- **Routing**: React Router v7
- **Icons**: Lucide React + custom sports SVGs
- **Fonts**: Montserrat, Plus Jakarta Sans, Bebas Neue

## 🏃 Running the Application

```bash
# Build for Production
npm run build

# Start Vite Development Server
npm run dev
```
The application runs locally at `http://localhost:5173/`.
